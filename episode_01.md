# Episode 1

## Using R as a calculator
- `1 + 100`: result 101
- `1 + `: result in prompt `+`
- either complete equation or press `Ctrl+C` or `Esc`
- order of operations:
```
Parentheses: (, )
Exponents: ^ or **
Multiply: *
Divide: /
Add: +
Subtract: -
```
- `3 + 5 * 2`
- `(3 + 5) * 2`: result 16
```
(3 + (5 * (2 ^ 2))) # hard to read
3 + 5 * 2 ^ 2       # clear, if you remember the rules
3 + 5 * (2 ^ 2)     # if you forget some rules, this might help
```

## Scientific notation
- `2/1000`: result 2e-04
- `5e3`: result 5000

## Mathematical functions
- `getwd()` # current working directory
- `sin(1)  # trigonometry functions` : result 0.841471
- `log(1)  # natural logarithm`: result 0
- `log10(10) # base-10 logarithm`: result 1
- `exp(0.5) # e^(1/2)`: result 1.648721
